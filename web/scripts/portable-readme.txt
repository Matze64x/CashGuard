CashGuard, portable version

Because this folder (CashGuard-data) is next to the program, CashGuard keeps all its own data in
here: its working copy of your data, its settings and the backups of your CashGuard file. Copy or
move the program together with this folder. Delete or rename the folder to use the data of an
installed CashGuard instead.

Your CashGuard file itself (the .json you open) stays wherever you chose to keep it.
