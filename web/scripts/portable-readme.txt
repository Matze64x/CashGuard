CashGuard, portable version

Because this folder (CashGuard-data) is next to the program, CashGuard keeps all its own data in
here: its working copy of your data and its settings. Copy or move the program together with this
folder. Delete or rename the folder to use the data of an installed CashGuard instead.

A backup file (if you chose one in the settings) stays wherever you chose to keep it.
